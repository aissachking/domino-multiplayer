# تشكيلة — شكّل فريقين بالعدل

تطبيق ويب لتشكيل فريقين متوازنين لكرة القدم على ملعب بمنظور ثلاثي الأبعاد، يعمل بلا حساب وبلا خادم، وجاهز للتثبيت كـ PWA وللتحويل إلى تطبيق Android عبر Capacitor.

## التشغيل

```bash
npm install
npm run dev        # خادم محلي على http://localhost:5173 مع إعادة البناء التلقائي
npm run build      # بناء نهائي في dist/ (ملف index.html واحد مستقل)
npm test           # اختبارات خوارزمية الموازنة
```

اختبار المتصفح الكامل (السحب بالفأرة واللمس، التبديل، الحفظ، التصدير) يتطلب Python و Playwright:

```bash
npm run build && python3 -m http.server 4173 -d dist &
npm run test:e2e
```

## بنية المشروع

```
src/core/        منطق مستقل عن الواجهة
  balance.ts     خوارزمية الموازنة (قابلة للاختبار وحدها)
  formations.ts  التشكيلات لكل عدد من 1 إلى 11
  match.ts       بناء التشكيلة، القوة، التبديل والنقل
  storage.ts     الحفظ المحلي (localStorage)
src/pitch/       طبقة الرسم
  camera.ts      كاميرا منظور وإسقاط عكسي للسحب
  render.ts      الملعب والمجسمات (Canvas)
  PitchView.tsx  التفاعل: السحب باللمس والفأرة والحركة
src/export/      تصدير صورة PNG بمقاس 2160×2700
src/ui/          اللوحات والنماذج
```

## خوارزمية الموازنة

تقيس قوة كل فريق بتقييم أساسييه مضروبًا في ملاءمة كل لاعب للخط الذي يلعب فيه، ثم تقلّل مجموعًا موزونًا من: فارق القوة العامة، فارق كل خط (دفاع، وسط، هجوم)، فارق مستوى الحارسين، فارق عدد اللاعبين من كل مركز، وفارق الاحتياط. تبدأ من عدة توزيعات أولية ثم تحسّنها بتبديل اللاعبين حتى لا يبقى تبديل مفيد، وتحتفظ بأفضل البدائل لزر «إعادة التوزيع». اللاعب المثبّت لا يتحرك من فريقه.

## طبقة الرسم

المشهد مرسوم بكاميرا منظور حقيقية على Canvas، دون مكتبات خارجية، ليبقى خفيفًا وسريعًا على الهواتف المتوسطة. طبقة الرسم معزولة في `src/pitch/`، فيمكن استبدالها لاحقًا بـ Three.js ومجسمات بشرية حقيقية دون تعديل الخوارزمية أو الواجهة: يكفي أن تستقبل `SceneState` وتعيد مواقع اللاعبين على الشاشة.

## التحويل إلى Android

```bash
npm run android:init    # مرة واحدة: ينشئ مجلد android/
npm run android:sync    # بعد كل تعديل
npm run android:open    # يفتح المشروع في Android Studio
```

داخل تطبيق Android يُنصح بإضافة `@capacitor/share` و `@capacitor/filesystem` لمشاركة الصورة مباشرة، لأن WebView لا يدعم Web Share. نقطة الربط الوحيدة هي الدالة `tryShare` في `src/export/exportImage.ts`.
